The default Iced frontend supports up to four panes. Saved layouts retain the exact split tree, axes and ratios. Older version-1 one/two-pane layouts remain readable; the optional `tree` field supplies the extended topology. Loading a layout, including startup metadata, does not connect. Restore requires both the saved reconnect opt-in and an explicit user action.

Open **Window → Workspace** to save/load/restore a layout, find/reorder/color tabs and confirm bulk closes. Select the active tab's panes with the per-pane **Synchronized input targets** checkboxes, then use **ARM synchronized input** there to arm or disarm mirroring. **Mode → Sync Input...** opens Workspace when fewer than two targets are selected; with at least two selected, it toggles arm/disarm. Selection alone never arms sync. When armed, the status-bar badge counts N selected targets, not successful deliveries: a selected focused source is eligible to mirror to the other live selected panes, while an unselected focused source receives input only to itself even though the targets remain armed. For example, with A and B selected and armed, focusing an unselected C sends input only to C. Target edits, tab changes, reconnects and closes disarm mirroring. The focused source pane must accept each PTY write **before** any synchronized targets receive that data; a failed or disconnected source never silently sends input to a different tab or split pane. Delayed paste confirmations retain the original target IDs and are cancelled if focus or the target plan changes.

Closing a pane shuts down its owned PTY/process worker. A workspace can contain up to four SSH terminal panes; interactive SFTP terminals are not serializable SSH workspace layouts. Restores validate profile references, unique pane indices, split axes and bounded ratios before connecting.
